AudiobookShelf API Reference

AudiobookShelf is a self-hosted audiobook and podcast server. The API lets you manage libraries, sync listening progress across devices, stream audio, and control playback programmatically.

Base URL: {server}:3333/api/v1
Auth: Personal token or user/pass
Format: JSON
Content: Audiobooks + Podcasts

Overview

AudiobookShelf organizes media into Libraries. Libraries contain Items (books or podcasts). Items contain Tracks (audio files) and Chapters. Users have per-item Progress tracking their listening position.

Data Model

Library
Container for a media type (audiobooks or podcasts).
Item
A single book or podcast in a library.
Track
An audio file within an item. Multiple tracks = chapters.
Progress
User's listening position within an item.

Authentication

Authenticate using a personal access token (recommended) or email/password. Tokens are scoped to a user and inherit their permissions.

Authorization: Bearer AbsToken xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
http
# With personal token
GET /api/v1/libraries
Authorization: Bearer AbsToken xxxxxxxxxxxxxxxxxxxxx

# With email + password (returns token)
POST /api/v1/login
Content-Type: application/json

{ "email": "user@example.com", "password": "secret" }
json
{
  "user": { "id": "usr_abc", "username": "alice", "type": "user" },
  "token": "AbsToken xxxxxxxxxxxxxxxxxxxxx",
  "mediaProgress": [],
  " bookshelves": []
}

Libraries

Libraries are the top-level containers in AudiobookShelf. Each library has a type (book or podcast) and its own media files.

GET /libraries

List all libraries visible to the authenticated user.

json
{
  "libraries": [
    {
      "id": "lib_audiobooks",
      "name": "Audiobooks",
      "icon": "book",
      "mediaType": "book",
      "bookCount": 247,
      "lastUpdate": "2025-05-29T18:00:00Z"
    },
    {
      "id": "lib_podcasts",
      "name": "Podcasts",
      "icon": "microphone",
      "mediaType": "podcast",
      "podcastCount": 12
    }
  ]
}

Get statistics for a library — total items, total duration, genre breakdown.

Library Items

Items are the individual books or podcasts in a library. Use filter and sort params to query them.

GET /libraries/{library_id}/items

List items in a library with optional filtering, sorting, and pagination.

ParameterInTypeDefaultDescription
sortquerystringmedia.metadata.titleSort field: media.metadata.title, media.metadata.authorName, media.duration, media.numTracks, createdAt, updatedAt, media.size
orderqueryenumascasc, desc
filterquerystring—Filter expression (see Filter Syntax below)
limitqueryint10Max results per page (max 100)
offsetqueryint0Pagination offset
minifiedqueryboolfalseReturn compact response (less data)
includequerystring—Comma-separated includes: media,progress,rss
bash
# Get books by a specific author, sorted by duration
curl "http://localhost:3333/api/v1/libraries/lib_abc/items?filter=author=Dune&sort=media.duration&order=desc" \
  -H "Authorization: Bearer AbsToken xxxx"

# All unfinished books with progress
curl "http://localhost:3333/api/v1/libraries/lib_abc/items?filter=missing=0&include=progress" \
  -H "Authorization: Bearer AbsToken xxxx"
