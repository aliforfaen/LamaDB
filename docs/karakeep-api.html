Karakeep API Reference

The Karakeep REST API lets you manage bookmarks, lists, tags, highlights, assets, and backups programmatically. Everything you need to build a powerful dashboard or automation layer on top of your Karakeep instance.

Base URL: {server}/api/v1
Auth: Bearer token (JWT)
Format: JSON
40+ endpoints

Overview#

Karakeep is a self-hostable bookmarking and read-it-later service. Its REST API exposes every core entity — bookmarks, lists, tags, highlights, assets, and backups — so you can build dashboards, integrations, and automation on top of it.

Bookmark Types

link
A URL bookmark with optional crawled metadata, screenshot, PDF, or full-page archive.
text
A plain text note or snippet stored directly as a bookmark.
asset
An uploaded file — image or PDF — stored and attached to a bookmark.

Base URL & Server

VariableDefaultDescription
addresshttps://try.karakeep.appYour Karakeep server address. Include no trailing slash.
full base URL{address}/api/v1All endpoints are relative to this base path.

Authentication#

All API endpoints require a Bearer token in the Authorization header. Generate an API key from your Karakeep instance at Settings → API Keys → New API Key.

Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
Granular scopes: API keys can now be scoped to specific resources. Give agents read access to bookmarks but not admin actions, for example. Check the API key settings in your Karakeep instance.
http 
GET /api/v1/bookmarks
Authorization: Bearer your-api-key-here
Content-Type: application/json

Pagination#

All list endpoints use cursor-based pagination. Pass the cursor from a response's nextCursor field to fetch the next page. When nextCursor is null, you've reached the end.

ParameterInTypeDefaultDescription
cursorquery string— Opaque cursor from a previous response's nextCursor field.
limitquery integer20 Number of items to return per page.
json
{
  "bookmarks": [...],
  "nextCursor": "abc123xyz"   // pass this as ?cursor=abc123xyz for next page
}
includeContent: Endpoints that return bookmarks accept an includeContent query param (defaults to true for backward compatibility, but will switch to false in future releases). Pass ?includeContent=false if you don't need the full archive content — it'll save bandwidth.

Errors & Rate Limits#

The API uses conventional HTTP status codes. When rate limiting is enabled, exceeding the per-IP limit returns a 429 with a Retry-After header.

2xx
Success — request succeeded
4xx
Client error — check your request
429
Rate limit exceeded — retry after
5xx
Server error — Karakeep issue
StatusMeaning
200 OKRequest succeeded. Bookmark with this URL already existed (for link creation).
201 CreatedBookmark/resource was created successfully.
400 Bad RequestInvalid input data — missing required fields or malformed request.
401 UnauthorizedBearer token is missing, invalid, or expired.
403 ForbiddenYou don't have permission for this action (e.g., admin endpoint without admin role).
404 Not FoundThe requested resource doesn't exist.
429 Too Many RequestsRate limit exceeded. Check the Retry-After header for seconds to wait.

GET /bookmarks/search

Full-text search across all bookmarks. Searches titles, content, descriptions, and notes. Results are sorted by relevance by default. Supports the full Karakeep search query language.

ParameterInTypeDescription
qquerystringSearch query. Supports qualifiers like is:fav, #tag, list:name, url:github.com, age:<1w
cursorquerystringPagination cursor.
limitqueryintegerResults per page (default 20).
sortOrderqueryenumSort: relevance, newest, oldest
includeContentquerybooleanInclude full bookmark content (default true).
bash
# Favorited bookmarks from 2024 tagged "important"
GET /api/v1/bookmarks/search?q=is:fav%20after:2024-01-01%20before:2024-12-31%20%23important

# Untagged bookmarks in the "reading" list
GET /api/v1/bookmarks/search?q=list:reading%20-is:tagged

# Full-text search combined with qualifiers
GET /api/v1/bookmarks/search?q=machine%20learning%20is:fav
GET /bookmarks/check-url

Check if a URL already exists in the authenticated user's bookmarks. Useful for deduplication before creating a new bookmark.

ParameterInTypeDescription

Lists#

Lists are collections of bookmarks. They can be manual (you add bookmarks individually) or smart (they're defined by a search query and update automatically).

GET /lists

Retrieve all bookmark lists for the authenticated user, including both manual and smart lists.

json
{
  "lists": [
    {
      "id": "list_abc123",
      "name": "DevOps",
      "description": "Docker, Kubernetes, and infra links",
      "type": "manual",   // or "smart"
      "query": null,         // set for smart lists
      "createdAt": "2024-01-10T08:00:00Z"
    }
  ],
  "nextCursor": null
}

Create a new list.

Assets#

Assets are binary files — images and PDFs — uploaded to Karakeep. They're stored separately and attached to bookmarks via asset IDs. Useful for archiving screenshots, uploaded images, or PDF documents.

POST /assets

Upload a new asset (image or PDF) as multipart/form-data. Returns the asset ID and metadata.

FieldTypeReqDescription
filebinaryyesThe file to upload. Content-Type: multipart/form-data
bash
POST /api/v1/assets
Authorization: Bearer your-api-key
Content-Type: multipart/form-data

# Using curl
curl -X POST /api/v1/assets \
  -H "Authorization: Bearer your-api-key" \
  -F "file=@document.pdf"

# Response
{
  "id": "asset_xyz789",
  "filename": "document.pdf",
  "mimeType": "application/pdf",
  "size": 245760,
  "url": "/api/v1/assets/asset_xyz789"
}
GET /assets/{assetId}

Retrieve an asset's metadata or download the binary file directly.

Backups#

Create and manage full account backups as downloadable ZIP archives. Backups include bookmarks, lists, tags, highlights, and all metadata. Asset files are not included in backups.

GET /backups

List all backups for the current user.

json
{
  "backups": [
    {
      "id": "bk_abc123",
      "createdAt": "2024-11-01T12:00:00Z",
      "status": "ready",    // "ready", "pending", "failed"
      "size": 2048576      // bytes
    }
  ],
  "nextCursor": null
}
POST /backups

Trigger a new full account backup. The backup is generated asynchronously — poll GET /backups/{id} until status is ready.

GET /backups/{backupId}

Get metadata and status for a specific backup.

GET /backups/{backupId}/download

Download the backup ZIP file. Returns a binary stream with Content-Type: application/zip.

bash
GET /api/v1/backups/bk_abc123/download
Authorization: Bearer your-api-key

# Save to file
curl -L -o backup.zip \
  -H "Authorization: Bearer your-api-key" \
  "https://your-karakeep.com/api/v1/backups/bk_abc123/download"
DELETE /backups/{backupId}

Delete a backup. Useful for cleanup after downloading.

Search Query Syntax#

Karakeep's search is powered by Meilisearch and supports a rich query language combining full-text search with structured qualifiers. Spaces between conditions act as implicit AND.

Boolean Operators

AND / OR
Explicit boolean logic between conditions
- prefix
Negate a qualifier (e.g. -is:archived)
( ) grouping
Group conditions (groups themselves cannot be negated)
plain text
Full-text search across title, content, and notes

Qualifiers

Status qualifiers
is:fav
Favourited bookmarksis:fav
is:archived
Archived bookmarksis:archived
is:tagged
Bookmarks with at least one tagis:tagged
is:inlist
Bookmarks in one or more listsis:inlist
is:link
Link bookmarks onlyis:link
is:text
Text/note bookmarksis:text
is:media
Media bookmarks (images/PDFs)is:media
is:broken
Bookmarks with failed crawls or non-2xx responsesis:broken
Content qualifiers
url:
Match URL substringurl:github.com
title:
Match title substring (supports quoted strings)title:"rust async"
# or tag:
Match bookmarks with a specific tag#important, tag:"work in progress"
Time & Organization
list:
Match bookmarks in a specific listlist:reading
after:
Created on or after date (YYYY-MM-DD)after:2024-01-01
before:
Created on or before datebefore:2024-12-31
age:
Filter by creation age. Units: d, w, m, y. Use < / > for max/minage:<1w, age:>2w, age:<6m
feed:
Bookmarks imported from a specific RSS feedfeed:Hackernews
Source qualifiers
source:
Filter by capture sourcesource:rss, source:extension, -source:web

Example Queries

search examples
# Favorited bookmarks from 2024 tagged "important"
is:fav after:2024-01-01 before:2024-12-31 #important

# Archived bookmarks in "reading" list or tagged "work"
is:archived and (list:reading or #work)

# Untagged or unorganized bookmarks
-is:tagged or -is:inlist

# Recent bookmarks from the last week
age:<1w

# Full-text search combined with qualifiers
machine learning is:fav -is:archived

# All bookmarks from a specific RSS feed
feed:Hackernews

# Broken links from GitHub
url:github.com is:broken

Official Karakeep CLI tool for managing bookmarks, lists, and tags from the terminal. Supports auth config file for persistent credentials.

karakeep auth init
